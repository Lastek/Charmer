# What is this project
- Exploration of mediapipe and applications to AR for use with a realtime webcam. The main code for this lies in the mshow*.py files.

- Some other exploraitons into Universal Adversarial Prompts (UAP) for image and video defense against AI model training attempts against adversaries without license to do so. The main code lies in `./UAP` folder.

- Some other unorganized misc code.
